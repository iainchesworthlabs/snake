**This is the first release candidate of 0.2.0, the desktop game.** The version is now 0.2.0. `snake --version` and `snake --help` work on a machine with no display, and the release packaging starts the installed program, so a package that is missing a library fails before anything is published. `docs/playtest.md` has the script for the playtest with a child, the sounds to listen to, and the numbers a bot gets, which say that the unlock targets of 2,000 and 3,000 in Classic are meant for experts.
