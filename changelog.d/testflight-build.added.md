**The release workflow can build the iPhone and iPad version for TestFlight.** It signs the game for the App Store, has Apple check it and uploads it, and the people the owner adds as testers install it from the TestFlight app (the app is called ICL Snake there). It is off until the owner turns it on. An ad-hoc build for registered devices is still possible. See "Installing on an iPhone or iPad" in the documentation. Not yet tried on a device.
