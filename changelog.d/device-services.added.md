**On a phone the game buzzes, and goes quiet when you put it away.** Eating gives a light tap and a crash a harder knock on Android and iOS (the package asks for the vibrate permission, which Android grants at install and never asks you about). The music and the sounds stop when the game is put away and come back with it. The game can read the accelerometer through Qt Sensors, which the tilt controls use. A computer feels and changes nothing.
