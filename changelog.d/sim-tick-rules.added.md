**The rules of the game are in the simulation library.** A tick moves the snake one cell, with walls that end the game (Classic) or edges that wrap (Easy), ends the game when the head runs into the body (the tail cell counts as free because it moves away), grows the snake when it eats, places new food uniformly on an empty cell from the game's seed, and ends the game as a perfect game when the board is full. The same seed and inputs give the same game on every platform.
