**The game can be built for Android and iOS.** There are presets for an Android package (`android-arm64-debuggable`, `android-arm64-release`) and an unsigned iOS bundle (`ios-release`), an icon, a manifest that asks for no permission, and two workflows that build both and look inside what they make. The game is not yet fitted to a phone beyond that: tilt, haptics, the orientation lock and pausing when the phone is put away come next. Nothing has run on a device.
