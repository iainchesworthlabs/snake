**Scores are saved.** The game now keeps its leaderboards, recent names and unlocked modes in a file in your data folder, so they last between runs and updates. A damaged file is set aside as `save.snk.damaged` and the game starts afresh; a file written by a newer version is left alone. A game that makes the top 10 now waits for a name; the name entry and leaderboard screens come next.
