**The Linux package starts on older systems.** The first release candidate was built on the newest runner and called one maths function (`atan2f`) that glibc 2.43 gave a new version, so it would not start on Ubuntu 24.04, Debian 13 or any system older than glibc 2.43. The tilt code now uses the double-precision function, and the release workflow fails when a Linux package needs a glibc newer than 2.39.
